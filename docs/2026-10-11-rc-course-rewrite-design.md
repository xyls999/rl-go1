# 赛道重写设计（2027 RC 狗赛 · 地形族课程）

日期：2026-10-11
状态：历史初稿；以下数字有过时内容，以文末「2026-10-12 混合赛道实现说明」为准。

## 1. 目标

把训练赛道从"一小段障碍 + 大量平路"改成**每条赛道从头到尾都是同一种地形**，并重写课程与采样。
完成口径不变：**每族完成率 ≥ 0.9 且总完成率 ≥ 0.9**，出 400 回合验收报告 + 每族视频。

## 2. 参考来源与使用规则（重要）

参考仓库：`https://github.com/xyls999/27rc-dog-race`（`uwvwko-zzz/27rc-dog-race` 的 fork），
依据《2027 年足式机器人挑战赛比赛规则 V1.0》建的 MuJoCo 场地，含规则尺寸。

**使用规则：**
- 该仓库**只作尺寸参考**，且**只用于它确实存在的障碍**（高墙 / 限高框架 / 沟壑组合 / 砖木坑 / 轮胎阵 / 梅花桩 / 单木桥 / 绕桩）。
- 该仓库**没有**的（连续多层楼梯、连续上下坡、连续短沟、连续长沟）→ 用我们自己的设计，**不参考它**。
- **赛道布局、族表、赛道长度、起点位置、课程结构全部用我们自己的**，**不采用**它的 14 × 6 m 场地摆放、中心出发、8 障碍棋盘布局。
- 该仓库的网格实现也**不照抄**（它的轮胎是 48 凸环扇区/个，在 512 环境里会炸；我们用自己的轻量近似）。

| 高频摩擦参数 | 默认滑动摩擦 0.9，轮胎 1.1 |

## 3. 赛道带几何约定（我们自己的）

沿用现有 tile 架构，不引入官方 14×6 布局。

| 约定 | 值 |
|---|---|
| tile | `TILE_SIZE = 40`，`TILE_SPACING = 44`（不变） |
| 路线方向 | +X（固定世界方向，不变） |
| 起步引道 | `x ∈ [0, 2.0]` 平地（够 2–3 步建立步态） |
| 特征区 | `x ∈ [2.0, 34.0]`，**整段铺满该族地形，不允许插入平路** |
| 终点区 | `x ∈ [34.0, 35.0]`，出现在该族地形的**结束面上**（纯上坡族即在坡顶） |
| 横向可行带 | `y ∈ [-3.0, 3.0]`（6 m，对齐官方场宽） |

**高度约束**：纯上行族不强制回到 z=0，狗爬到高处终点即算完成；纯下行族出生在高台上。
`stairs_mixed` / `slope_mixed` 用"上—下"交替把净高差压在 ≤ 1.5 m 内。

## 4. 训练族（8 族，512 ÷ 8 = 64/族）

| 族 | 整段内容 | 关键尺寸 |
|---|---|---|
| `stairs_up_long` | 连续上行楼梯，一直到坡顶终点 | 级深 0.32–0.40；级高 `0.045 + 0.045d`（0.045–0.090）；每 8 级一个小平台（1 级宽） |
| `stairs_down_long` | 出生在顶部平台，连续下行到终点 | 同上反向 |
| `stairs_mixed` | 先连续上行（到约 1.2 m）再连续下行，重复 | 同上 |
| `slope_mixed` | 锯齿上下坡一直重复（"整段是坡"，净高差受限） | 坡角 `6° + 14°d`（6–20°）；上坡段 1.5 m + 平台 0.4 m，上/下交替 |
| `tire_field` | **整段轮胎带**：中心距 0.55（相切），**2 列宽**，沿赛道一直排到终点 | 外径 0.55 / 孔 0.33 / 厚 0.165（**严格照官方**）；摩擦 1.1 |
| `gaps_short` | 连续**短沟**（阈值以下 → 走过去） | 沟宽 `0.10 + 0.14d`（0.10–0.24）；落足平台 0.60；沟深 0.30 |
| `gaps_long` | 连续**长沟**（阈值以上 → **必须跳**） | 沟宽 `0.29 + 0.13d`（0.29–0.42）；落足平台 1.00；沟深 0.55 |
| `combined` | **历史初稿**：随机取 3–5 段；现已改为每图必备全部指定类别，详见文末更新 | 各按其自身尺寸 |

**冻结（先不训，代码与注册表挂起）**：`high_wall`、`clearance_frame`、`gap_assembly`、
`brick_bark_pit`、`stepping_stones`、`balance_beam`、`slalom`。
→ 已知问题记录：官方 `clearance_frame` 净空 0.29 m **低于 Go1 站高（0.32–0.35 m）**，
启用时必须抬到 ≥0.38 m；官方 `high_wall` 0.30 m 也高于 Go1 可爬高度（~0.16 m），需按能力下调。

## 5. 沟宽判断器

**目标**：短沟鼓励正常跨过；长沟要求四脚滞空跳过去；两者都要防刷分。

**单一阈值，不设范围**：`GAP_JUMP_THRESHOLD_M = 0.26`。判定就是一条线：

| 沟宽 `w` | 分类 | 行为 |
|---|---|---|
| `w ≤ 0.26` | 走过去 | 正常前进奖励已覆盖跨越；**不给** `leap_clear`；`four_feet_airborne` / `base_vertical_velocity_l2` 惩罚**保持开启**；掉进去照罚 |
| `w > 0.26` | **必须跳** | 进入窗口（近沿前 0.35 m ~ 远沿后 0.35 m）后**临时抑制** `four_feet_airborne` / `base_vertical_velocity_l2`；清空一次 `leap_clear` |

不设中间带。几何上 `gaps_long` 只生成 `> 0.26` 的宽度、`gaps_short` 只生成 `≤ 0.26` 的宽度；
单条沟宽上限 0.42 m（0.8 m/s 速度上限下 Go1 的物理可跨越极限，再宽不生成）。

**几何 → 运行时的数据通路**：地形构建时把每族的特征事件写成
`course_feature_events = [(x0, x1, kind)]`（`kind ∈ {short_gap, long_gap, stairs, slope, tires}`），
经 env cfg 传给 `HierarchicalRuntime`，运行时建立 `_walker` / `_jumper` 两张按环境索引的掩码张量。
**不靠 height scan 反推**。

**`leap_clear` 的发放条件（全部满足）**：
1. 起跳点位于所属长沟近沿之前；
2. 落点位于远沿之后；
3. 全程无任何脚接触沟内；
4. 四脚同时滞空时长 ≥ `leap_clear.flight_seconds`；
5. 该窗口内前进量 ≥ `leap_clear.min_progress`；
6. **按沟 id 结算，每条沟只发一次**（在现有冷却之外再加 id 记账）。

**防刷分**：抑制器只在长沟窗口内生效；短沟区/平地乱蹦照吃 `four_feet_airborne` 惩罚；
`gap_intrusion` 与 `leap_clear` 保持**对称门控**（现有实现已如此）。

## 6. 奖励与契约

- **不改** `configs/rewards_stage1_gaps_v5.toml` 的项名与权重（`require_matching_reward_config` 会拒绝）。
- 只改 `runtime.py` 里**计算**这些项的代码（`leap_clear` / `gap_intrusion` / `four_feet_airborne` 的门控与窗口）。
- `GAP_FAMILIES` 需把两个新沟族加入（与 `leap_clear`/`gap_intrusion` 门控一致）。

## 7. 课程与采样

- 族列表改为上表 8 族；改族列表后**必须删 `lp_acrl_state.json`**（`LPSampler.load` 有族一致性守卫）。
- 初始难度**调高**：`difficulty` 起始不再从 0.1，改为 **0.30 起**（你要求"初始就高些"），上限沿用 `difficulty_max`。
- 楼梯踏步按你要求**偏高偏宽**（见 §4）。
- 起训 checkpoint：**从当前最佳模型续训** `checkpoints/stage1/2026-10-09_go1-phased10-robocon-lvl1k-s17-p1-d2/model_899.pt`。
- 段长/门禁沿用 `configs/curriculum_phases.json`（段长 900、gate completion 0.9、每族 ≥0.9 才升档）。
- `--episode-seconds` 必须 ≥100（赛道 34 m，按 0.45 m/s 约 75 s）。

## 8. 验收

1. 每族 256 环境单族评测：完成率 ≥ 0.9；
2. 512 混合评测 400 回合：总完成率 ≥ 0.9，碰撞/跌倒率达标；
3. 每族一段跟随视角视频（`--episode-seconds 133`，全程可见该地形）；
4. 出报告 `reports/evaluate_stage1_<ts>.json` + 逐族 join 表。

## 9. 明确不做

- 不采用官方 14 × 6 场地摆放、中心出发、8 障碍棋盘布局；
- 不训绕桩、限高框架、高墙、沟壑组合、砖木坑、梅花桩、单木桥（冻结）；
- 不修 `--certify` 死结（仓库既有互斥条件，与本次无关）；
- 不改奖励契约权重、不抬 `speed_min`（0.8 是硬边界）。

## 10. 风险

| 风险 | 处置 |
|---|---|
| 连续上行族净爬升过大（30 m × 爬升率） | 终点即在高处，不强制下坡；mixed 族用上/下交替把净高差压到 ≤1.5 m |
| 轮胎带网格过重（官方 48 扇区/胎） | 用轻量近似（低多边形环 + 平面孔洞），并把带宽限于 2 列；先验证 512 环境能建 collider |
| 判断器被刷（到处蹦） | 抑制器只在长沟窗口内；短沟/平地照罚；按沟 id 只结算一次 |
| 改族列表废掉旧 checkpoint 可比性 | 明确记录：本轮结果与旧 0.975 不可直接比较 |


## 11. 2026-10-12 混合赛道实现说明（覆盖前述初稿）

- 现行实际坐标：起点 x=3.0 m，障碍从 x=4.30 m 起，终点入口 x=33.10 m，最后障碍终点 x≈32.3–32.9 m；并非上文初稿的 x=2–34。
- 每一张 `combined` 图按如下模块排列：连续短沟 ×3（0.08–0.24 m，步行平台 0.65 m）→ 上坡/下坡、前段上下楼梯、第一段轮胎阵（各必有，三者顺序随种子变化）→ 连续长沟 ×3（0.29–0.42 m，每条仍有 1.10 m 落脚平台）→ 轮胎 2 排 → **窄踏面楼梯：上 8 级、下 8 级** → 轮胎直至接近终点。两段楼梯在同一张地图上每级高度完全相同，末段踏面沿 x 方向为 0.35 m、前段约 0.37–0.43 m；两段横向均铺满通道，无法绕开。难度影响坡高、统一级高、沟宽；不会删除某一类别。
- 轮胎阵使用外径 0.55 m、内径 0.33 m、厚 0.05 m、中心距 0.62 m、4 列、8 盒段/圈：厚度及中心距是**训练简化**，不声称与官方原尺寸完全一致。

## 12. 2026-10-12 独立全覆盖子课程与训练切换（覆盖旧 §4/§7）

- 课程族现为 **11 族**：`stairs_up_long`、`stairs_down_long`、`stairs_mixed`、`stairs_narrow_8_mixed`、`slope_up`、`slope_down`、`slope_mixed`、`tire_field`、`gaps_short`、`gaps_long`、`combined`。每个非混合族只铺自身类型，终点前最后一个障碍在 x≈30–33 m；混合族保持 §11 审核通过的版本。普通上下楼梯和窄踏面 8 上 8 下楼梯是两个独立族，后者完整重复 8+8 段（接近终点时可用同类短收尾段），前后升高共用逐图统一的级高。
- `slope_up` / `slope_down` 是只含坡的子课程：正/负坡段重复铺设，各段回到 z=0，并非一条单向净爬升/净下降的 30 m 长直坡。下凹坡段在主行走带 y=4–12 m 裁掉了遮挡它的水平底板；两侧留有底板。困难度改变坡角而不再缩短课程长度。轮胎阵和普通楼梯族也不再因低难度缩短到 11–14 m。短沟、长沟仍各自全程铺设。
- 训练配置 `configs/curriculum_phases_full.json` 独立使用 `lp_full_roster_state.json` / `lp_full_roster_acrl_state.json`，从旧 s27 `model_899.pt` 热启动。每阶段 512 环境，11 族各 46–47；门禁要求逐族至少 40 回合且**每族完成率均 ≥90%**才升档，保留低难度穿插。门禁对报告中缺失的计划族记 0 回合并保持原档，不会将缺族误算为通过。`scripts/watch_phased_curriculum_v3.sh` 可接受独立配置路径。
- 新基线 `2026-10-12_go1-full-roster11`，从 s01 起算；旧 8 族状态及其成绩**不与新 11 族门禁合并**。只有新阶段仿真评测能证明完成率，CPU 网格检查/视频不能代替实际通过。轮胎厚度/间距仍是训练简化；`combined` 逐沟走/跳门控仍待单独实现及验收。
