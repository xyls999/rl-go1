# v14 短沟专项教师（用户2026-10-16批准修改并开训）

目标：在v13十族共享教师失败后，先做纯短沟奖励覆盖的单独、串行教师实验，不把短沟、轮胎、长沟的奖励调整混合。仍保留同次512十族学生门、最终11族门与所有旧权重及停止标志；此实验只提供一个待验证教师。

1. 从远端当前源/配置SHA留存备份。在隔离`v14_work/`开发，先写并运行失败的纯tensor测试：短沟多段稳定支持/位移只能支付一次，跌倒/碰撞/站立/长沟/其他族不支付，reset后可重新支付，已有combined路径不变；检查所有短沟真实段≤24且元数据形状。
2. 加显式默认关闭的`GO1_V14_SHORT_REWARD=1`，训练期只读取既有`all_gap_segments`给纯`gaps_short`奖励，actor和命令/终止不变；现有`safe_segment`/`supported_short`纯短沟项追加且事件保持上限。留旧`no_progress`不动作为另一变量对照；轮胎和长沟奖励也不动。运行完整测试、16环境训练和评测冒烟，核查纯短沟奖励非零、其他族为零及权重未能力认证。
3. 用v13权重热启动新ID；单族目标命令0.35–0.8、难度轴与v13闸门相同（配置上限0.6，本首阶段难度层按既有采样器）、站立采样0、两个rank各512环境、900轮/critic预热150，独立新checkpoint；如果预检或冒烟失败不启动。仅一套Isaac，无watchdog、不自动p2，`lp_phased_stop.flag`保留。正式十族教师覆盖闸门待有各专项教师之后安排；训练退出0不表示短沟≥90%。
4. 保存SHA、训练日志、独立评测逐回合trace与结果；如短沟未达到90%，停在hold并诊断，不自动继续轮胎/长沟或蒸馏。

风险：从共享十族切到纯短沟同时改变采样分布与奖励，不能归因效果是单一奖励；后续如要因果比较，须同计划同seed使用关掉奖励的纯短沟对照训练。现有接触净力非精确触点，稳定支持奖励是训练侧代理，不认证实机安全或真正跳跃。
