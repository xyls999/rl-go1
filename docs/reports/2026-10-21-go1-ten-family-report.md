## 3. combined 为什么没做到（证据链）

受控实验（同一评测器、同一权重 v26，128 槽确定性）：

| 场景 | 完成率 | 摔倒率 |
|---|---|---|
| `course`：同一条混合路线，**零沟** | **1.000** | 0.0% |
| `gaps_short_dense`：纯窄沟、**间距 0.65 m（与入口同密度）** | **1.000** | 0.0% |
| `gap_course`：纯窄沟路线 | **1.000** | 0.0% |
| `combined`：混合路线 + 入口三沟 | **0.000** | ~100% |
| `combined` + 只留 **1 条** 11 cm 浅沟 | **0.000** | ~100% |

即：**混合地形本身能走，纯沟本身能走，二者组合即全灭**；问题不是沟宽/深/间距（已分别扫过：宽 ×0.25/×0.6、0.29–0.42 宽沟、深 0.115 浅沟、虚拟支撑面、间距 0.65/0.80/1.10），而是**"沟出现在混合场景"这一感知—行为组合**。

训练侧尝试（真实 combined 门禁）：

| 方案 | 轮数 | combined 门 | 摔倒率 |
|---|---|---|---|
| 纯 PPO（v30b） | 900 | 0 | 83% |
| 入口几何软化（v32a/v33a） | 400 | 0 | ~100% |
| 软终止 → 硬微调（v36a→v36c） | 1200 | 0 | 78.7% → 72.8% |
| 软终止 + 窄沟 credit（v38/v46） | 2800 | 0 | 72.7% / 73.6% |
| 特权观测教师（v47） | 800 | 0 | 81.1% |
| 虚拟支撑面（v48） | 800 | 0 | 97.2% |
| 单沟组合课程（v51） | 500 | 0（自身地形也 0） | 100% |
| 阶梯混合课程（v53） | 1000 | 0 | 76.7% |

与 P10 论文的差距：论文的两个核心机制我们只做了近似或未做——
1. **穿透式软动力学**（允许穿透 + 穿透体积/深度 × 前进速度惩罚 + 自动难度课程）；
2. **特权教师**（距离/高度/宽度 + 障碍类型 one-hot）——我们代码里虽有 `teacher_locomotion_obs`（精确地形几何），但直接给 actor 使用仍无效（v47）。

文献侧同类结论：Acrobotics(2025) 明确指出 Extreme Parkour 的策略"单个障碍可低概率完成，连续 5 个障碍 30 次尝试零成功"；Setup Policies(2021) 用"衔接策略"把随机序列成功率从 1.9% 提到 71.2%；ANYmal Parkour(Science Robotics 2024) 用"单障碍技能 + 高层选择器"处理组合。

## 7. 补充：分层选择器的可行性测试（2026-10-21 晚）

在投入分层选择器开发前，先用现有教师池做了**脚本化选择器**测试（等价于"完美的高层选择"）：
- 教师池：general=v26、tire=v15、long=v19p4；按位置切换（入口沟段→long，轮胎带→tire，其余→general）
- 修正了教师 GRU 状态推进（每步所有专家都更新，避免切换后冷状态）
- EPS=1.0（动作全部来自教师），真实 combined，128 槽确定性评测

结果：**completion 0.000 / fallen 1.000**（含跳跃专家在入口）。

结论：**底层专家在混合场景中本身不成立**，因此"高层选择器"缺少可用技能；在不重新训练场景鲁棒技能的前提下，分层选择器同样无法解决 combined。这与前述 v47/v55（特权观测）失败一致。

同时修正了此前 `combined_soft17`（去台阶）实验的误判：该族名未进入别名表、实际构建为空场地，导致 100% 的假阳性；修正后仍为 0%/全摔。

至此"软动力学近似"的三条实现（不终止、浅槽/虚拟支撑面、摔倒回弹）全部验证无效。
## 9. 补充：虚拟穿透（P10 穿透惩罚的工程近似）两次实验（v60 / v61）

思路：把训练地形的沟填浅（机器人可走过、不会摔死），同时用 `gap_intrusion` 惩罚"脚在沟范围内低于基准线"的每一步——等价于 P10 的"穿透深度 × 前进速度"惩罚；走过去持续挨罚、跳过去零成本。

| 版本 | 设定 | 门禁（真实 combined） |
|---|---|---|
| v60 | 沟深 7.5cm，沿用 `entry_multiplier=40` | completion 0/707，fallen **89.7%** |
| v61 | 沟深 3.5–4.5cm，`entry_multiplier=0`（修正标定，每步约 −0~−2.4） | completion 0/742，fallen **84.1%**，timeout 15.8% |

两次均无改善。v60 的失败可直接归因于一次性进入惩罚（−80×40=−3200）过强；v61 修正后仍失败，说明"走过 vs 跳过"的惩罚梯度不足以让策略在混合场景学会越沟。

至此实验矩阵（12 种训练方案 + 7 组几何/奖励消融）全部指向同一结论：在"单视觉策略 + 现有奖励/物理"框架内，combined 不可达。
