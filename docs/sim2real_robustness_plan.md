# Sim-to-Real 鲁棒性与泛化优化计划（基于 Tan et al. 2018）

依据：`docs/sim2real_paper.txt`（*Sim-to-Real: Learning Agile Locomotion For Quadruped Robots*，
Google Brain，arXiv:1804.10332，全文中文翻译）。
本文只描述**计划**；执行入口条件是"当前严格爬梯先恢复稳定 90% 完成率"（见 §5）。

## 0. 论文核心结论（本计划的直接依据）

1. **保真度是前提，优先于鲁棒技巧**（论文 §V-A / 图 6）：精确 URDF（实测质量、质心、估算惯量）+
   **理想直流电机执行器模型**（τ=Kt·I，I=(V_pwm−V_emf)/R，V_emf=Kt·q̇，PWM 由 PD 给出，含
   **分段线性的力矩饱和**）+ **显式控制延迟**。论文中三者缺任一个，真实机器人直接失败；
   基线仿真 + 随机扰动训练仍无法跨越现实差距。
2. **鲁棒控制器**（§V-B）：
   - 逐 episode **动力学随机化**（表 I 全表：质量 80–120%、电机摩擦 0–0.05 Nm、惯量 50–150%、
     电机强度 80–120%、控制步 3–20 ms、延迟 0–40 ms、电池电压 14.0–16.8 V、接触摩擦 0.5–1.25、
     IMU 偏置 ±0.05 rad、IMU 噪声 0–0.05 rad）。
   - **随机扰动推力**：每 200 步（1.2 s）一次，持续 10 步（0.06 s），方向随机，130–220 N。
   - **紧凑观测空间**（§VI-B，图 9）：4 维 IMU 观测比 12 维（加 8 个电机角）**迁移更好**，
     尽管 12 维在仿真里更强——高维观测使训练分布相对测试分布稀疏，现实差距反而变大。
3. **奖励极简**（式 2）：`r = (pⁿ − pⁿ⁻¹)·d − w·Δt·|τⁿ·q̇ⁿ|`，w=0.008，全程未调参；
   步态风格靠**开环参考**表达，而不是靠奖励塑形。
4. **混合策略**（式 3）：`a(t,o) = ā(t) + π(o)`，`ā` 是用户给定的周期开环信号，`π` 是反馈修正；
   通过调节 `ā` 与 `π` 输出边界，可在"完全人工指定"到"完全自主学习"之间连续变化。
5. **评测方法**（§VI）：训练 100 个控制器（不同超参与种子）→ 按**仿真**回报取前 3 → 每个跑 3 次
   （9 次均值）；用**连续回报差**（而非成功率）量化现实差距；随机化是"**鲁棒性↔最优性**"权衡
   （均值下降、跨环境标准差下降，图 7/8）。
6. 训练规模：25 条并行 rollout × 1000 步，约 700 万步，PPO，两层 MLP，尺寸靠超参搜索。

## 2. 执行计划（四阶段，每项都有验收门槛）

### P1 保技能 + 现实化（延迟/观测/执行器）
- **1.1 显式延迟 + 延迟随机化**：观测历史缓存 + 在 `nΔt − t_latency` 处线性插值（论文 §V-A.b）；
  `t_latency` 随机 0–2 控制步（0–40 ms），默认 20 ms。
  文件：`envs/runtime.py`（观测快照队列）、`envs/config.py`（`hier_obs_delay_steps`、随机开关）。
  验收：固定 seed 完成率下降 ≤5 点；随机条件门槛不掉；注入延迟后的仿真轨迹与真实日志一致。
- **1.2 观测污染**：IMU 角偏置 ±0.05 rad、角速度噪声、关节角偏置/噪声、height scan 随机 dropout；
  从 0 起按 25%→50%→100% 放大。
  文件：`envs/config.py`（`enable_corruption=True` + 各噪声项）。
  验收：每档完成率回归 ≤3 点。
- **1.3 执行器力矩包络现实化**：核对 `ActuatorNetMLP` 的力矩-速度包络 vs Go1 实测；
  增加 `motor_strength_scale` 随机化 0.8–1.2；如包络与实测差异大再加分段线性饱和（论文 §V-A.a 图 4）。
  验收：力矩-速度包络误差 ≤10%（饱和区与拐点位置）。

- **1.4 频域 / 波形现实化（电机波与控制环频率）** ← 论文里最容易被忽略的一类差距
  依据（译文原文）：L86「给电机施加**正弦形式**的期望轨迹…仿真与实测吻合（图 4）」；
  L39「控制环频率**并不完全固定，约 150–200 Hz**」；L76「**增益较大时仿真稳定但真实系统振荡**」；
  L91「用**一个时间步的 PWM 尖脉冲**测延迟：MCU PD ≈3 ms、上位机 15–19 ms」；
  L159–162 小跑参考为**正弦**：`s̄=0.3sin(4πt)`、`ē=0.35sin(4πt)+2` → **2 Hz**。
  - **1.4.1 正弦扫频辨识（幅值/相位）**：不只跑"一条正弦"，而是对每条关节在
    **0.5 / 1 / 2 / 5 / 10 Hz × 2–3 个幅值** 下发正弦指令，比较仿真与实机的
    **幅值衰减与相位滞后**。若 1–5 Hz 段相位滞后超差，说明缺少电机电气/机械带宽：
    在仿真中加一阶滞后（时间常数 τ≈L/R 与机械时间常数）并把它纳入随机化。
    验收：0.5–5 Hz 幅值误差 ≤15%、相位误差 ≤15°；10 Hz 只要求不振荡发散。
  - **1.4.2 控制环频率/抖动现实化**：把控制步长从固定 20 ms 改成**按实机测量分布采样**
    （论文：3–20 ms；我们的 policy 环是 50 Hz，但需实测上位机非实时抖动），
    并允许 **intra-episode 抖动**（目前只有 per-episode）。随机化课程同 P2.1。
    验收：抖动 ±10% 下完成率不回归；实测频率直方图与仿真采样分布 KL < 0.1。
  - **1.4.3 PD 增益稳定性差异**：论文指出约束式执行器在高增益下"仿真稳、实机振荡"。
    Go1 用 `ActuatorNetMLP`，需确认它不存在同类假稳定：用**阶跃 + 扫频**对照实测，
    并在训练中随机化 `kp/kd ±20%`（否则实机调增益就失效）。
    验收：增益 ±20% 范围内不振荡；阶跃响应超调与实测差 ≤20%。
  - **1.4.4 参考步态/目标步频的现实化**：论文小跑参考频率 = **2 Hz**，
    我们当前 `step_frequency.target_hz=2.2`、`phase_contact.flat_hz=2.4` 与之接近。
    计划：实测 Go1 **可稳定执行的步频区间**，用它界定 `ā(t)`（P3.4）与目标步频，
    避免参考频率超出真实执行器带宽。
    验收：实机步频区间内的跟踪误差 ≤仿真误差 ×1.3。
  - **1.4.5 延迟测量脚本化**：复现论文的 PWM 尖脉冲法，测 Go1 的 PD 级/上位机级延迟，
    写进部署配置并与仿真注入值对齐（论文 3 ms / 15–19 ms）。
    验收：三种延迟（PD/推理/端到端）实测与仿真注入误差 ≤2 ms。

- **1.5 动作空间现实化（腿空间参数化）** ← 论文 §IV-B，我第一版遗漏
  论文用**腿空间** (swing `s`, extension `e`) 表达动作，映射 `θ₁=e+s, θ₂=e−s`，
  并明确指出：**关节空间**里自碰撞使大量姿态无效、有效动作分布在若干非凸区域 →
  学习更难，且实机上等于在冒险执行自碰撞姿态；腿空间可用**矩形边界**同时剔除无效姿态并覆盖
  大多数有效姿态。我们目前直接输出 12 个关节偏移（关节空间）→ 属于"可用但更危险"的一侧。
  计划：每条腿把 `(e,s)` 映射到 **thigh/calf** 两个矢状面关节，**hip abduction 保持直通**
  （它是外展不是平面运动）；边界取 URDF 软限位的矩形子集；
  **用当前已验证策略的平均姿态初始化中心**，保证不破坏已有技能。
  验收：A/B（关节空间 vs 腿空间）在同一门槛下完成率 ≥原策略 −2 点，且自碰撞/碰撞率下降；
  实机侧：随机采样动作中无效姿态比例 = 0。
- **1.6 观测空间审计（论文 §IV-B 的"紧凑观测"）**
  论文明确**剔除 yaw（漂移）与电机速度（噪声大）**。逐项审计我们的 49 维 proprio：
  - `fixed_heading`（相对冻结轴）**不漂移** → 保留（论文剔除的是绝对 yaw）。
  - `dq×0.05`（12 维关节速度）论文会剔除 → 做**去 dq 的 ablation**，双门槛不降则采用。
  - `previous_action`（12 维）与 `gait_phase`（2 维）是我们的任务所需 → 保留。
  红线不变：**观测维度不再增加**，只做"噪声/偏置随机化"（P1.2）与"减法"。
  验收：去 dq 后固定门槛 ≥原 −2 点且随机条件门槛更好（论文图 9 同向）。
- **1.7 终止条件与 episode 结构对齐（论文 §IV-C）**
  论文：episode = **1000 步**或 **|tilt| > 0.5 rad** 终止。我们：133 s + `gravity_z > −0.5`
  （≈tilt>60°）+ 摔倒/碰撞/越界/终点。计划：
  - 随机化（P2.1）引入后**重新标定** tilt 与机身高度阈值（域随机化会改变统计）。
  - 增加**可选更严阈值 tilt>0.5 rad（≈29°）**做 A/B：论文用 0.5 rad 是为了剔除"快摔但没倒"的
    假高回报；我们若发现回报被"歪着冲线"污染，就切到 0.5 rad。
  验收：切换阈值后固定门槛与人工观看结论一致（录像抽查 5 回合）。

### P2 鲁棒化（随机化 + 推力，课程化引入）
- **2.1 论文表 I 的 Go1 映射**（全部逐 episode 采样）：质量 0.8–1.2×、惯量 0.5–1.5×、静摩擦 0.4–1.4、
  动摩擦 0.3–1.2、恢复系数 0–0.2、电机强度 0.8–1.2、控制步抖动 ±10%、延迟 0–40 ms、
  IMU 偏置/噪声（同 P1.2）。
  **随机化课程**：先 25% 半宽 → 50% → 100%，每段 ≥300 轮，且完成率不掉才扩宽。
  验收：随机条件门槛（64 回合 × 随机参数）完成率 ≥ 固定门槛 −10 点；
  跨参数回报**标准差下降 ≥30%**（论文图 8 指标）。
- **2.2 随机推力**：每 1.2 s 一次、持续 0.06 s、方向随机；**按质量重标**（论文是 5.7 kg 机器人
  受 130–220 N，等效 Δv≈1.4–2.3 m/s，切勿照搬绝对值），我们先用等效 Δv 0.3–1.0 m/s；
  只在课程前半启用。
  验收：固定门槛掉落 ≤5 点；"被推后恢复"子指标 ≥80%。
- **2.3 消融矩阵（论文 §VI-B 的三组对照）**：论文用"基线仿真 / 基线+随机扰动 / 改进仿真+随机扰动"
  三组证明**保真度优先于鲁棒技巧**（图 6：前两组真实机器人表现很差）。
  我们照此做四组，每组都跑**固定 + 随机**双门槛：
  | 组 | 延迟 | 观测污染 | 动力学随机化 | 推力 | 预期 |
  |---|---|---|---|---|---|
  | A 基线 | ✗ | ✗ | ✗ | ✗ | 固定门槛最高、随机门槛最差 |
  | B | ✓ | ✗ | ✗ | ✗ | 随机门槛改善 |
  | C | ✓ | ✓ | ✗ | ✗ | 进一步改善 |
  | D 全量 | ✓ | ✓ | ✓ | ✓ | 固定门槛↓、随机门槛最好、方差最小 |
  验收：能定量说出"每个机制贡献多少随机门槛提升、多少固定门槛代价"（写进报告表格）。
- **2.4 PPO / rollout 长度对齐（论文表 II）**：论文每次更新用 **25 条 × 1000 步**（整回合）rollout，
  训练 700 万步即收敛；我们 `num_steps_per_env=48`（0.96 s ≈ 2 个步态周期）。
  计划：以双门槛为判据，做 `48 / 96 / 128 / 192`（0.96 / 1.9 / 2.6 / 3.8 s，覆盖 2–8 个周期）
  的对照实验，并记录 GAE(`lam=0.95`)/`gamma=0.99` 的敏感性。
  验收：选出的更优设置必须在**随机门槛**上更好（否则不改）。
- 红线：**不扩 proprio 维度、不加大地形输入、不引入运行时触发器**（论文的紧凑观测结论）。

### P3 泛化到陌生环境（我们的"混合地形"要求）
- **3.1 地形域随机化**：路线**结构**重采样（段序/段数、沟宽 0.08–0.70、平台 0.7–1.1、
  台阶 3–16 cm、坡 6–30°），每 N 个 episode 重采样；`course_gaps` 保留为标准赛道做回归。
  文件：`envs/geometry.py`（`build_scene` 增加 `resample_on_reset` 与结构随机参数）。
- **3.2 留出集（held-out）**：新增 2–3 类**未训练**地形（不规则碎石、随机台阶阵列、宽窄交替沟），
  仅用于评估 → 作为"陌生环境"泛化指标。
- **3.3 速度/方向泛化**（论文 future work #1）：命令速度带随机 0.20–0.60、目标横向偏移 ±2 m、
  航向 ±10°。
  验收：held-out 完成率 ≥ 训练分布 −15 点；速度带两端（0.20 / 0.60）完成率 ≥80%。
- **3.4 混合策略保技能（论文式 3）**：把当前策略的**相位条件平均动作**蒸馏为开环 `ā(t)`，
  训练残差 `π(o)` 且输出边界 ±0.25 rad（先冻结 `ā`）。
  验收：残差策略固定门槛 ≥ 原策略 −3 点；单步观测丢失/延迟 100 ms 时仍不摔倒（`ā` 兜底）。

### P4 评测与部署规范
- **4.1 双门槛**：固定 seed（回归）+ 随机条件（鲁棒）。报告完成率/碰撞/摔倒/gap_fall/速度误差，
  外加连续 reality-gap 指标 `J = Δp·d − w·E_energy`（w 标定到两项量级相当，对齐论文 w=0.008 的做法）。
- **4.2 选型协议**（论文 §VI）：保留 top-N（N≥5）checkpoint，在**随机条件**下评估取最优，
  而不是只用最后一个 checkpoint。
- **4.3 部署前检查表**：实测延迟、执行器正弦跟踪、摩擦/质量辨识、力矩限幅、安全停机
  （摔倒/越界/碰撞终止）→ 写入 `docs/`。
- **4.4 评测规模与选型协议（论文 §VI 原文做法）**：论文训练 **100 个控制器**（不同超参/种子）→
  按**仿真**回报取 **top-3** → 每个跑 **3 次**（共 9 次）报告均值，并用**连续回报差**量化现实差距。
  我们落地：把爬梯的每个 attempt checkpoint 都当候选（现成 N≥6，目标 N≥10），
  在**随机条件**下算仿真回报 J → 取 top-3 再跑固定门槛与录像。
  验收：报告同时给出"固定门槛完成率"与"随机条件 J 均值±标准差"两张表，选型以 J 为准。

## 3. 风险与红线
- 随机化必然掉峰值（论文图 7/8）：必须**课程化引入 + 双门槛分别记录**，否则无法归因。
- 已验证的 90% 档位与 0.32–0.45 速度带是**回归基线**，不得直接被改动覆盖；改动一律"新 run + 双门槛对比"。
